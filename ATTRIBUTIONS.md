# Attributions

## Product visuals

The Cat Is Here desk, studio, notebook, cat, plant, and map-scene illustrations were created for this project through generative-image and local editing workflows. The project does not claim that these images were drawn by hand.

The round sleeping-cat logo was generated by the project creator with GPT and adapted for the Cat Is Here interface. Local prompt notes exist for several visual iterations but are excluded from the public repository cleanup.

## Font

The current interface includes `assets/fonts/pingfang-xingchen.ttf` (平方星辰体), downloaded from [100font](https://www.100font.com/thread-1005.htm). The font owner's listing describes it as free for online and offline commercial media use, while prohibiting modification, derivative fonts, direct sale of the font library, and unlawful use: [平方星辰体 official listing](https://www.17font.com/font/detail/f0830cf0333f11edbee8c71897523854.html).

This project uses the unmodified font in the interface and does not sell it separately. The public repository should retain these source and license links; redistribution questions beyond the published wording should be confirmed with the rights holder.
